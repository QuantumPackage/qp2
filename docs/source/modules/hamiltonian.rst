===========
hamiltonian
===========

Parameters of the Hamiltonian.

The only parameter currently stored in the |EZFIO| database is
:option:`mu_erf`, the range separation parameter that cuts
the electron-electron interaction in range separated models.
 
 
 
EZFIO parameters 
---------------- 
 
.. option:: mu_erf
 
    cutting of the interaction in the range separated model
 
    Default: 0.5
