===============
selectors_cassd
===============

Selectors for |CAS-SD| calculations.

The selectors are the determinants on which the matrix elements
:math:`\langle i | H | \psi \rangle` of the perturbation are applied.
In this module they are ordered so that the generators of
:ref:`module_generators_cas` come first, followed by the rest of the
wave function.
