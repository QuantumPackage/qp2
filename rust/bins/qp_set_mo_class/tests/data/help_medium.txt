

Usage:
  
  ./qp_set_mo_class_medium_name_xyz [-a <range>] [-c <range>] [-d <range>]
      [-h] [-i <range>] [-q] [-v <range>] [--] EZFIO_DIR
  
Arguments:
  
  EZFIO_DIR            EZFIO directory. 
  
Options:
  
  -a  --act=<range>    Range of active MOs. 
  -c  --core=<range>   Range of core MOs. 
  -d  --del=<range>    Range of deleted MOs. 
  -h  --help           Prints the help message. 
  -i  --inact=<range>  Range of inactive MOs. 
  -q  --query          Print the current MO classes. 
  -v  --virt=<range>   Range of virtual MOs. 
  
Set the orbital classes in an EZFIO directory. The range of MOs has the 
form : "[36-53,72-107,126-131]".
