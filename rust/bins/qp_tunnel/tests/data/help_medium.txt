

Usage:
  
  ./qp_tunnel_medium_name_xyz [-g] [-h] [--] (EZFIO_DIR|ADDRESS)
  
Arguments:
  
  (EZFIO_DIR|ADDRESS)       EZFIO directory or address. 
  
Options:
  
  -g  --get-input           Downloads the EZFIO directory. 
  -h  --help                Prints the help message. 
  
Creates an ssh tunnel for using slaves on another network. Launch a server 
on the front-end node of the cluster on which the master process runs. 
Then start a client ont the front-end node of the distant cluster.
