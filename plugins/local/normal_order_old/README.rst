================
normal_order_old
================

Older variants of the normal ordering contractions, used by the
transcorrelated methods.

The module contains the normal ordering of the two-body interaction
on the |HF| density, in the bi-orthogonal parametrization
(`normal_ordered.irp.f`), the contractions reduced to the occupied
and virtual orbitals (`normal_ordered_contractions.irp.f`), and
older versions of the normal ordering routines
(`normal_ordered_old.irp.f`, `normal_ordered_v0.irp.f`) kept
alongside the current ones.
